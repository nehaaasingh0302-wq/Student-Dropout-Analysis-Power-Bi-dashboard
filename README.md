🎓 Student Dropout & Academic Performance Analysis Dashboard
📌 Project Overview

This project is an interactive Power BI dashboard designed to analyze student enrollment, graduation, and dropout patterns. The dashboard helps identify key demographic, academic, financial, and economic factors that influence student success.

The project demonstrates end-to-end Business Intelligence skills including data cleaning, data transformation, data modeling, DAX calculations, KPI development, and dashboard design.

🎯 Business Problem

Educational institutions often struggle to identify factors that contribute to student dropout rates and academic performance.

This dashboard aims to answer questions such as:

What percentage of students graduate, drop out, or remain enrolled?
How do scholarships impact student outcomes?
Does financial status influence dropout rates?
Which courses have the highest graduation rates?
How do demographic factors affect student performance?
